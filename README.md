# 📊 Data Analytics Project – SQL & Power BI

## Overview

An end-to-end Data Analytics project using **SQL** for data analysis and **Power BI** for interactive visualization.

## Tools Used

* SQL
* Power BI
* Excel / CSV
* DAX

## Project Workflow

**Raw Data → Data Cleaning → SQL Analysis → Power BI Dashboard → Business Insights**

## Key Analysis

* Data cleaning and exploration
* KPI analysis
* Category and performance analysis
* Trend analysis
* SQL queries using filtering, aggregation, `GROUP BY`, `HAVING`, and `JOIN`

## Dashboard

Created an interactive Power BI dashboard with KPIs, charts, filters, and business insights.

## Skills Demonstrated

**SQL | Power BI | Data Analysis | Data Visualization | DAX | Business Insights**
